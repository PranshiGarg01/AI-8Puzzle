# AI-8Puzzle-Visualizer

An interactive 8-Puzzle Problem Solver for an Artificial Intelligence course assignment.

## Technologies
- HTML5
- CSS3
- JavaScript ES6
- Bootstrap 5

## Features
- Pixel-art arcade inspired interface
- Home page and navigation
- Puzzle solver, comparison page, and algorithm guide are being developed

## Search algorithms
Planned: BFS, DFS, DLS, IDDFS, GBFS, and A*.
Heuristics planned for GBFS and A*: Misplaced Tiles and Manhattan Distance.
