INTERPRETATION

Read the results

Expanded nodes

States removed from the frontier and processed.

Generated nodes

Candidate states created while exploring neighbors.

Maximum frontier

Largest number of pending states waiting to be explored.

Solution depth

Number of moves in the returned path. BFS and A* with these heuristics are optimal for equal-cost moves.
